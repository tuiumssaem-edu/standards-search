# standards-search

2022 개정 특수교육 교육과정 성취기준 검색 앱입니다. 활동을 입력하면 관련 성취기준(일상생활 활동 포함)을 교과별·학년 순으로 보여 줍니다.

- `index.html` 한 파일로 동작합니다(데이터 포함, 서버 불필요). 브라우저에서 열면 됩니다.
- 수록: 별책 3 기본 교육과정, 별책 2의 공통·선택 중심 교육과정(특수교육 고유 교과). 창의적 체험활동, 유치원 교육과정은 없습니다.
- 출처: 교육부 고시 제2022-34호(2022. 12. 22.) 「2022 개정 특수교육 교육과정」
- 검색 결과는 후보입니다. 지도안에 쓰기 전에 원문과 대조해 주세요.
